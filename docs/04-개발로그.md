### ✅ 공용 서랍 페이지 추가 · 2026-09-02

- **한 일**: `drawer.html` 신규(단일 파일, 외부 라이브러리 없음). 단톡방에 흘러간
  링크를 분류·태그·검색으로 모아보는 페이지. `index.html`에는 두 앱을 오가는
  전환 링크만 추가.
- **재사용한 것**: `index.html`의 gviz 읽기, CSV 파서(따옴표 처리), 머리글 찾기,
  날짜 처리, 링크 추출. 강조색만 보라(`#6F4A8E`)로 바꾸고 배경·글꼴·카드는 그대로.
  초록은 맛집·카페(`--cafe`)가 이미 쓰고 있어 피함.
- **막힌 점**
  1. 작업지시서가 가리킨 원본 시트는 「제한됨」이라 브라우저가 못 읽음.
     이메일을 뺀 공개용 시트를 읽도록 구조를 바꾸고, 원본에 `추천공개` 탭을 추가.
  2. 공개용 `추천응답` 탭이 원본 응답 탭을 그대로 가져오는 바람에 공유자가 전부
     «익명»으로 나오고, 이미 지웠던 이메일 2건이 다시 공개됨. `추천공개`를
     거치도록 고쳐 둘 다 해결.
  3. 콘솔 안내 문구에 줄바꿈이 들어가 문자열이 끊겼고, 스크립트 전체가 파싱되지
     않아 페이지가 한동안 빈 화면이었음.
- **배운 것**
  - 이름 변환은 브라우저가 아니라 **시트에서** 끝내야 이메일이 새지 않는다.
    브라우저가 강사매칭을 읽게 만들면 강사 8명 이메일을 전부 공개해야 한다.
  - 열은 **위치가 아니라 이름으로** 찾는다. 폼에 질문을 넣으면 순서가 바뀐다.
  - 시트 공유 설정을 건드리면 기존 IMPORTRANGE 승인이 풀려 `#REF!`가 된다.
    값이 잠깐 정상으로 보이는 건 구글이 이전 값을 캐시하기 때문이니, 캐시가
    만료된 뒤 다시 확인할 것.
  - **푸시 전 로컬 확인을 건너뛰지 말 것.** 위 3번이 그래서 생겼다.
  - GitHub Pages는 `max-age=600`이라, 잘못된 버전이 한 번 올라가면 사용자
    브라우저가 최대 10분간 그걸 붙잡는다. 고친 뒤에는 주소 뒤에 `?2`를 붙여
    확인하도록 안내할 것.

### ✅ 학교 상세에 특이사항 섹션 추가 · 2026-09-02

- **한 일**: 메모 폼(초등/중등/기관 3섹션) 응답을 읽어 학교별 특이사항을 표시.
  방문 전 알아야 할 내용이라 주차 섹션 위에 배치. 회색 계열로 주차·맛집과 구분.
- **막힌 점**: 폼을 섹션으로 나누면 학교명이 `학교(초등)`/`학교(중등)`/`기관명`
  여러 열로 갈라짐. 앱은 `학교` 한 열만 읽으므로, 시트의 `○○공개` 탭에서
  **열 이름 패턴으로 찾아 하나로 합쳐** 내보내도록 처리.
- **배운 것**: 위치 기준(`C2:G`) 수식은 폼을 손대는 순간 깨진다. 열 이름으로
  찾으면 섹션을 더 추가해도 수식을 고칠 필요가 없다.

### ✅ 이메일 분리 · 2026-08-31

- **한 일**: 시트를 둘로 나눔. 원본(폼 응답·강사 이메일)은 「제한됨」, 공개용은
  이메일을 이름으로 바꾼 사본만 담아 「링크가 있는 모든 사용자·뷰어」.
  앱이 읽는 곳을 공개용으로 교체하고, 강사매칭을 읽던 코드를 제거.
- **왜**: 앱이 시트를 읽으려면 공개여야 하는데, 그러면 폼 응답에 딸려온 선생님
  이메일까지 함께 공개된다. 구글 시트는 파일 하나 안에서 탭만 가릴 수 없다.
- **배운 것**: IMPORTRANGE로 넘어온 타임스탬프는 텍스트가 아니라 날짜
  일련번호(`46264.82817`)로 도착한다. `(값-25569)*86400000`으로 변환.
