### 추천응답 탭의 실제 열 (**원본 시트** 기준, 순서 그대로)

앱이 읽는 건 이 탭이 아니라 `추천공개`를 거친 공개용 `추천응답`입니다.
아래는 `추천공개` 수식을 쓸 때 참고할 원본 모양입니다.

```
타임스탬프 | 링크 | 이름 | 분류 | 태그 | 한줄 메모 | 가격 | 이메일 주소 | 공유자 표시
```

⚠️ **주의 세 가지**

1. `이메일 주소`가 2번이 아니라 **8번째**입니다. → 열을 **위치가 아니라 이름으로** 찾으세요.
   폼에 질문을 추가하면 순서가 또 바뀝니다.
2. `공유자 표시`는 폼에서 삭제한 질문의 **잔여 열**입니다. 항상 비어 있으니 무시하세요.
3. `태그`는 체크박스라 한 칸에 `강의용, 전자기기`처럼 들어옵니다.
   구분자가 `,`인지 `, `인지 확정되지 않았으니 **`/\s*,\s*/`로 둘 다 처리**하세요.
   쉼표가 값 안에 있으므로 **CSV 파싱은 따옴표를 제대로 처리하는 파서**가 필요합니다.
   `split(',')`로 하면 열이 밀립니다.

### 분류 값

## 만들 것

### 1. `drawer.html` (신규)

**화면 구성**

```
┌────────────────────────────────┐
│ [🗂 학교 정보] [🧺 공용 서랍]    │ ← 두 앱 전환
│ 공용 서랍                       │
│ 단톡방에 흘러간 링크, …          │
│ ┌────────────────────────────┐ │
│ │ 🔍 이름, 메모, 태그, 공유자  │ │
│ └────────────────────────────┘ │
│ [전체][물건][병원·약국][기타]    │ ← 분류 탭
│ (#강의용 5)(#정형외과 2) →      │ ← 태그, 빈도순
├────────────────────────────────┤
│ 12개              [새로고침]    │
├────────────────────────────────┤
│ ┌────────────────────────────┐ │
│ │ 접이식 미니 삼각대           │ │
│ │ 가볍고 튼튼합니다            │ │
│ │ #강의용 #촬영                │ │
│ │ ● 미현쌤 · 12,900원 · 9/2 ⧉ │ │ ← 색 점은 이름별 고정
│ │   [쿠팡에서 보기]            │ │
│ └────────────────────────────┘ │
├────────────────────────────────┤
│       ［ ＋ 정보 추가 ］         │ ← 하단 고정, 폼으로
└────────────────────────────────┘
```

**기능**

- [ ] 추천응답 탭을 gviz CSV로 읽어 카드 목록 표시 (최신순)
- [ ] 검색 — 이름·메모·태그·공유자를 한 번에
- [ ] 분류 탭 — 전체 / 물건 / 병원·약국 / 기타
- [ ] 태그 필터 — 빈도순 정렬, 복수 선택 시 AND
- [ ] **태그가 3개 미만이면 태그줄 자체를 숨김** (초반 화면이 어수선해지지 않게)
- [ ] 링크 주소로 이동 버튼 라벨 결정 (아래 참고)
- [ ] 링크 복사 버튼
- [ ] 공유자는 `공유자` 열을 그대로 읽기. 이름 변환은 시트에서 이미 끝나 있음
      (열이 없으면 «익명»으로 두고, 무엇이 없는지 콘솔에 남길 것)
- [ ] 공유자 이름별 색 고정 (이름 문자열 해시 → 팔레트)
- [ ] 폼에서 돌아오면(visibilitychange) 자동 새로고침
- [ ] 상태별 화면 4가지: 불러오는 중 / 비어 있음 / 검색 결과 없음 / 불러오기 실패

**이동 버튼 라벨 판별**

지도와 쇼핑몰을 같은 자리에서 처리합니다. 병원이 스키마 변경 없이 들어오는 핵심입니다.

```
map.kakao, kko.to            → 카카오맵
map.naver, naver.me          → 네이버지도
google.com/maps, maps.app.goo.gl → 구글맵
coupang                      → 쿠팡
smartstore, shopping.naver   → 네이버
11st / gmarket / oliveyoung / daiso / aliexpress → 각 이름
그 외                        → 링크
```

**타임스탬프 처리**

`2026. 9. 2 오후 3:12:05` 형태입니다. `new Date()`로 파싱하면 브라우저마다 결과가
달라지므로, **정규식으로 연·월·일 숫자만 뽑아** 정렬과 표시에 쓰세요.

## 디자인

**mc7의 `index.html`을 먼저 읽고 색·글꼴·둥글기·간격을 맞춰 주세요.**
다만 두 페이지가 구분돼야 하므로 **강조색만 다르게** 가져갑니다.

- mc7이 쓰는 강조색을 확인하고, 그와 명확히 구분되는 색을 서랍에 쓰세요
- 초록 계열(`#1F6F5C` 등)을 제안하되, mc7과 겹치면 다른 색으로
- 나머지(배경·본문색·카드 스타일·글꼴)는 mc7과 동일하게

공유자는 **카드 하단 정보줄에 작은 색 점 + 이름**으로 표시합니다.
색은 이름별로 고정합니다 — 이름을 읽지 않아도 누가 올렸는지 알아보게 하는 게 목적입니다.
(초기안은 카드 왼쪽 세로 색 띠였으나, 존재감이 과해 축소했습니다.
식별 기능과 표시 크기는 별개입니다.)

## 지켜야 할 원칙

1. **단일 HTML 파일.** 파일을 쪼개지 마세요. 인아쌤이 직접 열어 수정할 수 있어야 합니다.
2. **npm·빌드 단계 추가 금지.** 브라우저에서 바로 열어 확인 가능해야 합니다.
3. **모바일 우선.** 카카오톡 내장 브라우저가 실사용 환경입니다.
4. **개인정보 표시 금지.** 이메일을 화면에 그대로 노출하지 마세요.
5. **날짜는 Asia/Seoul 기준.**
6. 사용자에게 보이는 문구는 **존댓말**, 사과하지 않고 다음 행동을 안내
   - ❌ "죄송합니다. 오류가 발생했습니다"
   - ✅ "시트가 «링크가 있는 모든 사용자»로 공유돼 있는지 확인해 주세요"
7. 색·글꼴은 CSS 변수(`:root`)에만 정의하고 재사용. 코드 안에 색상값 직접 쓰지 않기.
8. 외부 라이브러리 추가는 **먼저 물어볼 것.**
9. 주석은 **한글로, "무엇을"이 아니라 "왜"**를 적을 것.

## 작업 순서

1. **저장소를 클론하고 `index.html`을 먼저 읽으세요.**
   gviz 읽기, CSV 파싱, 머리글 찾기, 날짜 처리, 링크 추출 함수가 이미 있습니다. **재사용하세요.**
   이메일 → 이름 변환 코드는 여기 없습니다. 그건 시트에서 처리합니다(위 「기술 구조」 참고).
2. 재사용할 부분과 새로 쓸 부분을 정리해 **먼저 보고**해 주세요.
3. `drawer.html` 작성
4. 로컬에서 열어 확인 — 목록이 뜨는지, 태그가 제대로 쪼개지는지
5. `index.html`에 전환 링크 추가
6. 커밋·푸시 전에 **무엇을 바꿨는지 알려주고 동의를 받으세요**
